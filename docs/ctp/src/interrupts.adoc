=== Interrupts

Interrupt tests are organized by the privilege level of the interrupts under test. Each suite boots to its
home mode and repeats every testcase in each supported lower privilege mode, raising interrupts through
the `RVTEST_SET_<type>_INT_<mode>` macros and letting the trap handler record and clear them.
Which interrupt sources a platform can raise is described by the `UDB_<TYPE>_SUPPORTED` parameters
(temporarily supplied by each configuration's `rvmodel_macros.h` until UDB provides them).

==== InterruptsSm Machine-Level Interrupts

These tests are run on any configuration with a standard machine mode. They boot to M-mode and exercise
every supported interrupt (MTI, MSI, MEI, STI, SSI, SEI, LCOFI) from M, S and U mode, including
delegation through `mideleg`.

==== InterruptsS Supervisor-Level Interrupts

These tests are run on any configuration with supervisor mode. They boot to S-mode with every
supervisor-level interrupt delegated and exercise STI, SSI, SEI and LCOFI from S and U mode without
touching machine-mode state.
